## 格式字符串告诉函数如何解释后面的参数

`printf` 使用一个格式字符串描述要输出的文字和占位位置。占位符与实际参数类型必须对应；这和 `cout` 根据类型选择插入运算的方式不同。

| 写法 | 含义 | 名称与约定 |
| --- | --- | --- |
| `std::printf` | 格式化输出函数 | printf 通常按 print formatted 理解 |
| `"%d"` | 按有符号十进制整数输出对应参数 | `d` 对应 decimal；这里匹配 `int` |
| `"%s"` | 输出以空字符结束的字符序列 | `s` 对应 string；参数必须指向有效的序列 |
| `"%%"` | 输出一个百分号 | 它不消耗一个普通数据参数 |

## 完整程序

```cpp
#include <cstdio>
int main() {
    int score = 95;
    char name[] = "Ada";
    std::printf("%s: %d%%\n", name, score);
    return 0;
}
```

输出 `Ada: 95%` 并换行。`%s` 使用 `name`，`%d` 使用 `score`，`%%` 写出百分号，不需要第三个数据参数。`name` 在这里是包含结尾空字符的字符数组；数组的具体机制可留到后续课程，这里先识别它提供的是文本。

## 不要漏掉引号

格式字符串必须是合法字符串，例如 `"%s"`。公开课件中漏引号的 `printf(%s, content)` 已在代码材料中修正。示例使用 C++ 头 `<cstdio>` 及限定名；公开材料中的 `<stdio.h>` 与 `printf` 是另一种常见接口写法。

## 可变参数格式化输出

`std::printf` 由 `<cstdio>` 提供，按格式字符串中的转换说明处理可变参数。转换类型、长度修饰符与实际经默认参数提升后的类型必须符合规定；这不是由格式文字驱动的任意自动类型转换。

`%d` 对应有符号十进制 `int`，`%s` 对应可访问的空字符终止字符序列，`%%` 输出百分号且不对应普通参数。格式字符串与参数不匹配、字符串缺少可访问终止符等错误可能导致未定义行为。

函数成功时返回写出的字符数，输出错误时返回负值。文本输出本身和该返回值是不同通道。公开 L02 第 7 页例子演示字符串及字符数组；本节点增加整数和百分号以明确格式参数关系，并保留独立可编译的 C++17 示例。
