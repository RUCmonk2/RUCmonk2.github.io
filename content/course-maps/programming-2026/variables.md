## 一个变量有名字、类型和当前值

变量不是印在纸上的等式。赋值语句会改变后续计算读到的值；类型则决定允许的取值和运算规则。先从一个能追踪全过程的整数开始。

| 写法 | 含义 | 命名与约定 |
| --- | --- | --- |
| `int score = 90;` | 声明并初始化整数变量 | `score` 是程序员选择的名字，不是关键字 |
| `score = score + 5;` | 读取旧值，加 5，再写回 | 左边是目标对象；右边先求值得到 95 |
| `=` | 初始化或赋值语法的一部分 | 不是数学上不改变对象的相等陈述 |
| `"score"` | 字符串中的五个字母 | 引号内的名字不会自动替换成变量值 |

## 完整程序

```cpp
#include <iostream>
int main() {
    int score = 90;
    std::cout << score << '\n';
    score = score + 5;
    std::cout << score << '\n';
    std::cout << "score" << '\n';
    return 0;
}
```

三行输出分别是 `90`、`95`、`score`。第一次输出读取初始化后的值，第二次读取赋值后的值，第三次输出字符串本身。

## 沿时间顺序代入

写下状态表：声明前没有这个局部变量；声明后值为 90；右侧 `score + 5` 算得 95；赋值后当前值改为 95。若再执行一次相同赋值，右侧使用的旧值已经是 95，因此得到 100，而不是重新回到 90 开始。

本例数值都很小。不要由此推断 `int` 能表示任意大整数；其范围与实现有关，有符号整数溢出不能当作可靠的循环取模行为。

## 对象、类型、初始化与赋值

`int score = 90;` 定义一个具有块作用域和自动存储期的整数对象，并进行初始化。后续 `score = score + 5;` 是赋值表达式：右侧经值计算后，结果存入左侧对象。初始化发生在对象建立时，赋值作用于已经存在的对象，二者语义不同。

`int` 的具体表示范围由实现决定，但标准给出最低要求；不能无条件假定它在所有实现上都是 32 位。整数算术受类型转换和可表示范围约束；C++17 中有符号算术溢出不是可依赖的定义良好结果。

名称的作用域决定哪里能引用该实体，存储期决定存储持续多久。字符串字面量中的字符序列不参与变量名称查找。示例限定于公开 L02 的标量变量和基本读写；数组、指针等不同对象模型不在此处预设。
