## 源码排版和输出排版是两件事

把一条输出语句分成多行书写，只是让源码好读。屏幕是否换行取决于写进输出流的字符，不取决于编辑器里按过多少次回车。

| 写法 | 输出效果 | 区别 |
| --- | --- | --- |
| `' '`、`" "` | 一个空格 | 前者是字符，后者是字符串，均可插入流 |
| `'\n'`、`"\n"` | 换行 | `\n` 在源码中是转义序列，不是两个普通输出字符 |
| `"\\n"` | 反斜杠加字母 n | `\\` 表示一个字面反斜杠 |
| `std::endl` | 插入换行并刷新流 | 不只是另一种没有副作用的换行拼法 |

## 完整代码

```cpp
#include <iostream>
int main() {
    std::cout << 1
              << 2 << '\n';
    std::cout << 1 << ' ' << 2 << '\n';
    std::cout << "\\n" << '\n';
    return 0;
}
```

输出三行：

```text
12
1 2
\n
```

第一句源码跨两行，输出仍先连续出现 `12`，然后才执行明确写下的换行。第三句故意输出转义写法的可见字符，用来区分“表示换行”和“展示反斜杠 n”。

## 逐字符预测

遇到输出题，按执行顺序列出每次写入的字符。整数 12 会格式化成字符 `1`、`2`；空格会形成一个分隔位置；换行把后续文字移到下一行。输出结果的空格、换行都属于答案，不能只检查数字是否对。

## 转义序列、记号间空白与流状态

字符串和字符字面量中的 `\n` 表示换行字符，`\\` 表示反斜杠。代码记号之间的排版空白通常不进入输出，而字面量内部的空格属于数据。预处理行和字面量自身另有语法规则，不能把“源码换行不影响输出”推广成源码中的任何换行都可任意删除。

标准操作符 `std::endl` 执行换行插入及流刷新；插入单个换行字符没有同样的显式刷新要求。缓冲和终端呈现还可能受运行环境影响，因而应比较程序产生的字符序列，而非仅看某一终端的即时显示。

对固定默认格式的整数和字符串输出，可按流插入顺序确定字节文本；跨平台文本模式可能对行结束表示进行转换。课程答案关注可见行与分隔关系，不把平台行结束编码差异当成算法错误。
