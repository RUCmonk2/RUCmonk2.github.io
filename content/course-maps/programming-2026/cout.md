## 输出流接收的是一串要写出的值

`std::cout` 表示标准输出流。把字符串、数字依次送给它，屏幕上就按顺序出现对应文字；它不会替你猜哪里该有空格。

| 写法 | 含义 | 名称与约定 |
| --- | --- | --- |
| `std::cout` | 标准输出流对象 | cout 是标准库规定的名字，常按 character output 理解 |
| `<<` | 此上下文中的流插入运算 | 相同符号用于整数时也可表示左移，须看操作数类型 |
| `"score="` | 要输出的文本 | 引号界定字符串，不作为字符输出 |
| `'\n'` | 一个换行字符 | 单引号界定字符，反斜杠开启转义写法 |

## 完整程序

```cpp
#include <iostream>
int main() {
    int score = 95;
    std::cout << "score=" << score << '\n';
    std::cout << 1 << 2 << 3 << '\n';
    return 0;
}
```

输出为：

```text
score=95
123
```

第一条语句依次写标签、整数和换行。第二条语句连续写三个整数，没有任何自动空格，所以得到 `123`，而不是 `1 2 3`。

## 链式写法可以拆开理解

`std::cout << "score=" << score;` 在本例中可以按先写字符串、再向同一个流写数值来读。`<<` 左侧已经是输出流，因此右侧整数按数字格式输出。若只是两个整数写成 `1 << 2`，则不是输出语句，不能用同样解释。

## 标准流插入与链式表达式

`std::cout` 是关联标准输出的 `basic_ostream<char>` 对象。相关插入运算重载按右操作数类型进行格式化或字符写入，并返回流引用，使连续 `<<` 可作用于同一个流。

数字格式还受基数、精度等流状态影响；本例采用初始默认十进制状态。连续插入不自动产生分隔符。输出流可具有缓冲，因此“执行插入”与“外部设备立即显示”不是完全相同的时序保证。

`<<` 是可重载运算符，同一个记号在内置整数操作数上表达移位。判读代码必须同时看类型和上下文。输出字符串字面量会写入其中的字符序列，界定引号及结尾空字符不按普通文本字符一同输出。
