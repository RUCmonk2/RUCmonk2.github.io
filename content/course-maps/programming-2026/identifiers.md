## 名字要合法，也要让人知道它表示什么

变量名首先必须被语言识别为一个标识符，然后才谈可读性。入门例子用英文字母、数字和下划线，避免把运算符或关键字误当成名字的一部分。

| 写法 | 结果 | 原因 |
| --- | --- | --- |
| `total_count`、`score2` | 合法的示例名字 | 数字可在后部，下划线可连接词 |
| `2ndscore` | 不可作为这样的标识符 | 不能以数字起头 |
| `money%owed` | 不是一个完整标识符 | `%` 是运算符记号，不属于这个名字 |
| `long` | 不能作为变量名 | 它是 C++ 关键字 |
| `x`、`X` | 是两个不同名字 | C++ 区分字母大小写 |

## 完整程序与输出

```cpp
#include <iostream>
int main() {
    int total_count = 2;
    int score2 = 90;
    int x = 3, X = 4;
    std::cout << total_count << ' ' << score2 << '\n';
    std::cout << x << ' ' << X << '\n';
    return 0;
}
```

输出两行，分别为 `2 90` 和 `3 4`。`x` 与 `X` 即使只差大小写，也储存不同对象的值。不过可读代码通常避免用这种细小差异表达重要概念，尤其需要他人检查时。

## 合法不等于适合使用

有些以下划线开头或含双下划线的名字保留给实现。入门练习可以直接采用小写单词和中间下划线，如 `student_count`，无需把“编译器没有立刻报错”当作名字都可随意使用的证据。

## 标识符、关键字与保留名字

C++17 标识符有专门词法规则，支持的字符范围不限于本节 ASCII 示例；入门子集可理解为字母或下划线起头，后续可含数字。关键字不能因上下文看似方便就用作普通变量名。名称大小写敏感，且名称查找按作用域规则进行。

含双下划线，或以下划线紧接大写字母开头的标识符保留给实现；以单下划线开头的名字在全局命名空间也受保留规则约束。因此推荐避开这些模式，但不能把建议简化成“所有下划线都非法”。

合法的名称还需在使用点有可见声明。同一实体的重命名必须更新对应引用；同名实体在不同作用域可能指代不同对象。公开 L02 第 24—25 页中的错误名字保留为注释实验，发布示例自身可正常编译。
