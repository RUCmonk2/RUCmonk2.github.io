## 先让一个完整程序正常结束

最小程序没有输出，也可以是正确程序。先理解入口、语句和结束状态，再往里面加入变量与输入输出。下面按常见的有操作系统环境、C++17 编译模式讲解。

| 写法 | 含义 | 名称与约定 |
| --- | --- | --- |
| `int` | 一种整数类型，这里是主函数返回类型 | 来自 integer；不是“任意精度整数” |
| `main` | 程序进入用户代码的主函数 | 标准规定的入口名称，不能随意改成别的名字 |
| `()`、`{}` | 参数列表、函数体 | 空参数列表与空函数体是不同概念 |
| `return 0;` | 结束主函数并返回成功状态 | `;` 结束这条语句；`0` 不是向屏幕打印字符 |

## 完整代码

```cpp
int main() {
    return 0;
}
```

先编译得到可执行程序，再运行。运行时屏幕没有文字是预期结果，因为代码没有输出语句。`return` 把控制权交还给运行环境，退出状态与标准输出是两个通道。

## 一次最小改动

增加输出需要声明相应的标准库设施：

```cpp
#include <iostream>
int main() {
    std::cout << "Hello\n";
    return 0;
}
```

预期输出为一行 `Hello`。双引号围住字符串，`\n` 表示换行。`#include` 是预处理指令，它后面不加语句分号；输出语句和 `return` 后面则需要分号。这里的缩进方便人阅读，花括号才规定函数体边界。

## 自己试试

1. 删除输出语句但保留 `return 0;`，屏幕上会出现 `0` 吗？
2. 把 `main` 改成 `start`，能否仍作为这个普通可执行程序的入口？

<!-- solutions -->
1. 不会。返回状态并非标准输出，正常情况屏幕保持空白。
2. 不能仅靠改名实现。常规 hosted C++ 程序需要合法的 `main`；链接阶段通常会因入口缺失而失败。

## 主函数与语句语义

本节点采用 hosted C++17 环境。程序应包含一个全局 `main`，其返回类型为 `int`；无参数的 `int main()` 是标准形式之一。`main` 中执行 `return` 会离开该函数并进行正常程序终止所规定的处理。执行流到达 `main` 末尾等价于返回 0，这是主函数特有规则，不应推广到任意返回 `int` 的函数。

复合语句用花括号限定语句序列及块作用域。表达式语句和返回语句按各自语法使用分号，预处理指令不依赖普通语句分号结束。换行与空格通常用于分隔记号和排版，但字符串内容、预处理行等位置仍有特定规则。

返回 0 表示正常成功终止；终止状态与向 `stdout` 输出文本是不同机制。最小程序没有可见输出不构成错误。公开示例对应 L02 第 2 页；有关头文件、名称查找及输出流的细节沿关联节点继续阅读。
