## 给反向传播安排一位独立的检查者

如果一个权重略微变大，损失会变大还是变小、变化多快？中心差分通过两次前向直接估计这个量，用来核对手推或自动微分的结果。小模型适合逐个参数检查，大模型可先检查单层和随机方向。

| 记号                 | 含义                | 为什么这样记              |
| -------------------- | ------------------- | ------------------------- |
| $\theta_j$           | 第 j 个参数         | theta 常表示参数集合      |
| $e_j$                | 第 j 个坐标单位向量 | 只改变一个参数的方向      |
| $\varepsilon$        | 正的扰动尺度        | 小 epsilon 常用来表示小量 |
| $g_j^{\mathrm{num}}$ | 数值梯度估计        | num 是 numerical 的缩写   |

## 中心差分、误差尺度与检验边界

在可微且足够光滑的邻域内，以

$$
g_j^{\rm num}=\frac{J(\theta+\varepsilon e_j)-J(\theta-\varepsilon e_j)}{2\varepsilon}
$$

估计偏导数。Taylor 展开给出二阶截断误差；舍入与浮点消减则使极小扰动不可靠。应结合函数尺度扫描几个扰动量，同时记录绝对误差与 $|g_j-g_j^{\rm num}|/\max(1,|g_j|,|g_j^{\rm num}|)$，不能机械套用单一阈值。

例如 $J(w)=w^3$，在 w=2 处中心差分在精确算术下为 $12+\varepsilon^2$。六权重例子的梯度为 $(1.05,0.525,1.05,0.525,1.3125,3.99)$；详解提供标准库 Python 程序，直接用前向损失独立核对每个分量。

对单位方向 v，也可比较 $\nabla J^\top v$ 与方向中心差分，两次前向即可完成。但单个方向无法排除与它正交的梯度误差；应多方向检查或在小模型逐坐标验证。

检验须固定参数、样本、随机性及状态，保持损失的 sum/mean、正则项与输出维度归一化完全一致。ReLU 在0处的中心差分为0.5，与实现约定的反向值0不同并不能构成错误证明，因为此处不可导。先避开拐点和随机控制流，在同一光滑分支检查。校验通过只支持被检目标在被检点的导数正确，不保证任务设计和泛化可靠。
