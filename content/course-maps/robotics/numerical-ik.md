## 把一次“大误差”拆成局部修正

Newton 迭代只用当前构型附近的线性模型求一步修正。更新之后模型的位置也变了，因此必须重新计算正运动学、误差和雅可比。

| 记号         | 含义           | 注意事项               |
| ------------ | -------------- | ---------------------- |
| $e_k$        | 目标减当前位姿 | 角误差归到主值区间     |
| $J(q_k)$     | 当前任务雅可比 | 本例为 $3\times3$      |
| $\Delta q_k$ | 一次关节修正   | rad，并非关节速度      |
| $\lambda$    | 阻尼参数       | 正值限制敏感方向的放大 |

## 局部线性化、阻尼与终止条件

在当前构型处，$f(q_k+\Delta q)=f(q_k)+J(q_k)\Delta q+O(\|\Delta q\|^2)$。忽略高阶项后求 $J\Delta q=e$，再更新 $q_{k+1}=q_k+\Delta q$。对于可逆方阵可直接求解线性方程，无须显式计算逆矩阵。只有在解附近、导数足够光滑且雅可比非奇异等条件下，才能期待 Newton 的局部快速收敛；远离解时全步长可能反而增大真实误差。

带阻尼的子问题是最小化 $\|J\Delta q-e\|_2^2+\lambda^2\|\Delta q\|_2^2$。一阶条件给出 $(J^\top J+\lambda^2I)\Delta q=J^\top e$，等价解为 $J^\top(JJ^\top+\lambda^2I)^{-1}e$。在奇异值方向上，普通倒数替换为 $\sigma/(\sigma^2+\lambda^2)$；它限制小奇异值引起的放大，却也会留下更大的局部残差。

位置与角度混合时，范数依赖单位和权重。可以引入正定权重 $W$，用 $\|W^{1/2}(J\Delta q-e)\|^2$ 替代未加权误差。无论采用何种更新，成功条件都应检查真实正运动学的残差；本例分别检查位置与角误差。步长很小但残差仍大是停滞，达到次数上限是此次未收敛，二者都不能标成找到逆解。线搜索、限幅和重启是补充策略，不是全局有解的保证。
