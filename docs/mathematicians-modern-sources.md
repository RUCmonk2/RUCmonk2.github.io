# 现代数学家人物志：内容与图像证据

核验日期：2026-10-19。范围为本文件所属12人，不改变其他组。双语文案为本页原创简写，现代定理表述与历史原文作了区分。

## 内容选择与条件

- 罗素：1901悖论、1908类型论、1910–1913《数学原理》；未把逻辑主义计划说成已经完成。
- 哥德尔：一阶逻辑完备性与算术理论不完备性分开；不完备性保留一致性、有效公理化及足够算术能力条件。ZF的相对一致性不是绝对一致性证明。
- 图灵：1936–1937论文年份同时表示写作/发表；通用机器与不可判定性、1950机器智能提议、1952反应扩散。
- 丘奇：λ演算、1936判定问题、与Rosser合流性定理；不把Church–Turing论题当作普通形式定理，不把合流性当作终止性。
- 冯·诺伊曼：有限二人零和博弈且允许混合策略；量子算子强调定义域；1945 EDVAC设计明确是合作成果。
- 柯尔莫哥洛夫：概率用σ代数和可列可加性；KAM保留非退化、小扰动、非共振条件；复杂度固定通用机并说明不可计算。
- 陈省身：1944内在高斯–博内证明限定闭、定向、偶数维黎曼流形；1946陈类；1974与James Simons合作。
- 韦伊：Mordell–Weil限定数域上阿贝尔簇；曲线点数界限定光滑、射影、几何连通；1949猜想不当作其个人全部已证结果。
- 格罗滕迪克：1957同调代数、1960起与Dieudonné的EGA、与Artin等合作的étale上同调；不将韦伊误列为博士导师。
- 埃尔德什：1932伯特兰定理新证明，1947概率存在性方法，1959与Rényi的固定边数随机图；不混淆早期G(n,m)与独立边G(n,p)模型。
- 香农：1937论文/1938发表，1948有限离散熵与独立同分布信源，离散无记忆信道的渐近可靠性；不等同零错误或语义价值。
- 米尔扎哈尼：2007模空间体积（2g−2+n>0）、2008简单闭测地线计数（闭双曲曲面，g≥2）、2013–2015合作的轨道闭包结果。

## 关系证据

`mentorship`表示明确指导，可包含注明的博士后关系；`influence`表示文献或理论承接。`parallel`均明确标注“编辑对照”，不暗示相识、共同论文或直接影响。

- **cantor-russell** · `influence`：罗素研究康托尔以来的集合论与数学基础时发现悖论，迫使人们检验不受限制的集合构造。这里记录问题的发展，不把悖论归为康托尔已经证明的结论。 [证据](https://plato.stanford.edu/entries/russell-paradox/)
- **russell-godel** · `influence`：哥德尔1931年论文直接研究《数学原理》及相关系统的不可判定命题。这是对形式化工程的深入分析，并不是两人的博士师承。 [证据](https://plato.stanford.edu/entries/goedel-incompleteness/)
- **hilbert-godel** · `influence`：希尔伯特希望以有限方法保障数学的一致性；哥德尔的第二不完备性定理为这类计划施加严格限制。限制依赖理论的有效性和算术能力等条件。 [证据](https://plato.stanford.edu/entries/goedel-incompleteness/)
- **hilbert-church** · `influence`：希尔伯特的判定问题要求通用判定程序。丘奇在1936年证明一阶逻辑有效性不存在这样的算法，回应的是明确的研究问题。 [证据](https://mathshistory.st-andrews.ac.uk/Biographies/Church/)
- **church-turing** · `mentorship`：图灵在丘奇指导下完成普林斯顿博士研究，1938年获学位。两人此前分别提出不同的可计算性模型；指导关系不意味着图灵机由丘奇提出。 [证据](https://mathshistory.st-andrews.ac.uk/Biographies/Turing/)
- **godel-turing** · `influence`：图灵1936年论文讨论与哥德尔不完备性结果相关的不可判定性，并以机器模型分析机械过程。这里是基础问题和方法的延展。 [证据](https://www.cs.virginia.edu/~robins/Turing_Paper_1936.pdf)
- **hilbert-von-neumann** · `mentorship`：冯·诺伊曼在1926–1927年于哥廷根随希尔伯特研究。他此前已在布达佩斯取得博士学位，因此这是博士后指导关系。 [证据](https://mathshistory.st-andrews.ac.uk/Biographies/Von_Neumann/)
- **godel-von-neumann** · `influence`：冯·诺伊曼很早理解哥德尔工作的意义，并在授课中转向讲解其结果。两人后来同在高等研究院工作；这条线记录理论影响。 [证据](https://www.ias.edu/kurt-g%C3%B6del-and-institute)
- **laplace-kolmogorov** · `parallel`：编辑对照：拉普拉斯组织古典概率计算；柯尔莫哥洛夫用测度论公理处理无限过程。这是研究主题的历史比较，不声称两人有直接联系。 [证据](https://mathshistory.st-andrews.ac.uk/Biographies/Kolmogorov/)
- **shannon-kolmogorov** · `parallel`：编辑对照：香农熵依赖一个概率分布；柯尔莫哥洛夫复杂度依赖固定通用机器上的最短描述。两者都研究信息，但对象与可计算性不同。 [证据](https://www.mathnet.ru/eng/ppi68)
- **gauss-chern** · `influence`：陈省身的高维高斯—博内定理内在证明，延展了把曲率与整体拓扑联系起来的几何传统。这是跨代的理论承接，不是直接师承。 [证据](https://www.ams.org/bull/1946-52-01/S0002-9904-1946-08487-6/)
- **riemann-chern** · `influence`：陈省身在黎曼流形上研究曲率、联络与整体不变量，把内在几何推进到高维。这里记录理论语言的承接，不是两人的人际关系。 [证据](https://www.ams.org/bull/1946-52-01/S0002-9904-1946-08487-6/)
- **weil-chern** · `influence`：阿伦德费尔与韦伊1943年证明高维高斯—博内公式；陈省身1944年给出内在证明。此线强调具体结果之间的推进，不把韦伊写成他的博士导师。 [证据](https://www.ams.org/bull/1946-52-01/S0002-9904-1946-08487-6/)
- **riemann-weil** · `parallel`：编辑对照：黎曼研究复变量ζ函数；韦伊研究有限域曲线的ζ函数。后者的「黎曼假设」对应零点规律，并不等同于原猜想。 [证据](https://www.ams.org/bull/1949-55-05/S0002-9904-1949-09219-4/S0002-9904-1949-09219-4.pdf)
- **weil-grothendieck** · `influence`：韦伊猜想要求有限域代数簇具有类似拓扑的上同调。格罗滕迪克与合作者建立étale上同调，为这份纲领提供关键工具；韦伊不是他的博士导师。 [证据](https://www.mathunion.org/fileadmin/ICM/Proceedings/ICM1966.1/ICM1966.1.ocr.pdf)
- **dedekind-grothendieck** · `parallel`：编辑对照：戴德金用理想整理代数数的整除结构；概形理论以环的素理想构造空间。这里并列两种结构语言，不把跨世纪对照伪装成人际师承。 [证据](https://numdam.org/item/PMIHES_1960__4__5_0/)
- **euler-erdos** · `parallel`：编辑对照：欧拉把桥梁问题化为顶点和连接；埃尔德什与雷尼研究随机选边后的整体结构。两者可放在图论长线中阅读，但没有直接人际关系。 [证据](https://www.cse.cuhk.edu.hk/~cslui/CMSC5734/erdos-1959-11.pdf)
- **riemann-erdos** · `parallel`：编辑对照：黎曼用复分析探索素数分布；埃尔德什参与了素数定理的初等证明。共同问题连接两者，「初等」不代表证明简单。 [证据](https://mathshistory.st-andrews.ac.uk/Biographies/Erdos/)
- **turing-shannon** · `influence`：香农1956年研究用两个状态构造通用图灵机，直接沿用图灵的计算模型。状态少不意味着整个机器描述或计算过程都简单。 [证据](https://mathshistory.st-andrews.ac.uk/Biographies/Shannon/)
- **riemann-mirzakhani** · `influence`：米尔扎哈尼研究黎曼曲面及其模空间的体积、曲线和动力系统，推进了关于曲面连续变化的问题。两者相隔一百多年，这是理论对象的承接。 [证据](https://mathunion.org/fileadmin/IMU/Prizes/Fields/2014/news_release_mirzakhani.pdf)
