# 内容与发布维护

## 栏目与内容归属

- 关于：个人介绍，仍在首页 `#about`。
- 学习：可持续维护的课程与实践指南，唯一入口 `/learning/`。不再在首页或教程页手写第二份总目录。
- 写作：随想、复盘、阶段记录，路径继续使用 `/blog/`。显示名称不影响旧链接。
- 友链：独立 `/links/`，不再在关于中重复列出。

学习内容分类规则见 [learning-catalog.md](learning-catalog.md)。公共 HTML 中的导航也使用这套称呼；教程正文里的“博客”“教程”等一般名词不需机械替换。

## 文章发布边界

文章放在 `content/blog/zh` 或 `content/blog/en`，同一篇的不同语言使用同一个 slug。公开元数据示例：

```yaml
title: "文章标题"
date: "2026-09-01"
updatedAt: "2026-09-20"
status: published
summary: "简短摘要"
```

- 新草稿明确写 `status: draft`。为兼容旧文章，未写 `status` 仍视作已发布；`draft: true` 也会阻止公开。未知状态值会报错，不会猜测。
- 草稿可不填齐标题、日期；读取层会在渲染前过滤。列表、首页、详情路径、语言切换、站点地图与订阅源共用这一层。
- 语言版本只有已发布才显示切换入口；文件存在不等于可公开。
- `date` 是首次发布日期；`updatedAt` 是可选的实质内容更新日，不随样式变化刷新。两者均写带引号的 `YYYY-MM-DD`，更新时间不能早于发布日。
- 列表按首次发布日期排序。正文显示更新日；Atom、Open Graph、JSON-LD、站点地图使用 `updatedAt`，缺省回退到 `date`。
- 页面显示绝对日期，不把“今天 / 几个月前”固化在静态产物中；日期统一按 UTC 格式化，避免跨时区少一天。
- 当前只有一个中文 Atom 源 `/api/feed/atom.xml`，英文界面也指向它；不要使用无效的语言查询参数模拟英文订阅源。
- 状态不是保密措施：公开仓库与 Git 历史仍能读到源文件。私密草稿放在仓库外；`public/` 不经过草稿过滤，所有附件都需先确认可公开。

## 静态页、旧链接与更新时间

- 公开 HTML 只维护 `public/assets/`；根目录 `assets/` 是冻结的历史副本，不做同步。
- `/tutorials/` 是学习目录兼容入口；原指南、课程和 `/blog.html` 的旧地址继续保留。
- 学习条目的 `updated` 由目录管理，课程各章的 sitemap 日期继承该课程日期。通用入口没有可靠内容日期时省略 `lastModified`，不虚构构建日。
- 新页面的返回链接应指向对应栏目；旧锚点消失时同步修复所有引用。

## 发布检查

CI 按顺序运行 `lint` → `test:content` → `build` → `check:export`，全部成功后才上传构建产物。

- `test:content`：用独立测试样本验证显式发布、旧文兼容、草稿过滤、未发布翻译、非法状态和日期，并验证真实文章的元数据。
- `check:learning`：唯一目录、首页精选、标题、课程切换、中英文路径、兼容入口、canonical 和站点地图。
- `check:site`：检查导出 HTML 的本地链接、锚点及引用资源，核对公开文章与草稿输出、Atom / sitemap / JSON-LD 的日期。
- `check:export`：运行后两项。先构建再执行，防止检查旧产物。

自动检查不验证外部站点是否在线、图片内文字、版权授权或所有客户端状态。导航与布局调整还需桌面及手机预览；课程内容变更需人工核对正文、习题与交互结果。
