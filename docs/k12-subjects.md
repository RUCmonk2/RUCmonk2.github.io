# 中小学全科学习导航

## 本次范围

K12 总入口现在位于 `/learning/k12/`，提供 16 个学科入口。数学已有 199 节详细双模式讲义；新增 15 个学科的 37 条分学段学习框架，共 122 个模块。每个模块独立写明知识主线、具体任务、折叠的检查要点和常见误区。新增六个跨学科项目，包含步骤、相关学科和可交付成果。

新增内容定位为**学习框架与任务**，不是逐知识点的完整教材，也不冒充已经完成全科双模式讲义或全科知识网络。外语以英语任务为主；日语、俄语、德语、法语和西班牙语只有衔接提示，未提供独立课程模块。地方与校本课程未展开。

课程范围参照教育部义务教育课程方案（2022 年版）及普通高中课程方案（2017 年版 2020 年修订）。模块划分与原创任务由本站自行组织，不等同于课标逐条复刻，不指定全国统一年级进度。初中综合科学与分科并列说明；小学历史地理启蒙通过语文、科学、道法承接。高中各科同时包含主干与选学方向，具体范围需对照学生教材。

## 路由与兼容

- 全科总览：`/learning/k12/`。
- 数学原总览移到：`/learning/k12/mathematics/`。
- 数学三学段、199 节讲义、图谱 hash 与因式工坊 URL 保持原地址。
- 新学科：`/learning/k12/subjects/{subject}/`，15 个路由。
- 学段锚点：`#primary`、`#middle`、`#high`（只生成适用学段）。
- 模块锚点：`#{stage}-{module}`，搜索结果可直达。
- 英文路径保留英文页面元信息，教学正文为中文，页面明确提示。
- 学习目录新增“中小学学习”分组，数学探索分组保留数学知识网和实验室。

## 内容与页面

- `src/data/k12-subjects/subjects.json`：逐科原创内容；学科 → 学段 → 模块。
- `src/data/k12-subjects/index.ts`：类型、学段、领域、数学目录适配、来源与项目。
- `src/components/k12/subject-directory.tsx`：关键词、学段、领域组合筛选；空结果与重置；数学结果直达现有讲义。
- `src/app/[locale]/learning/k12/subjects/[subject]/page.tsx`：静态生成的学科框架、学习路线、相关学科、任务和检查要点。
- `K12Shell` 的 `section` 区分全科导航和数学导航；复用纸色、墨色、阅读布局及响应式规则。

整理增加科目时，不要强制人文学科套用符号表或演算模板。语文强调文本证据，历史强调史料与解释，科学强调模型和实验，艺术强调作品与过程，体育强调个人进步，实践课程强调真实任务与反馈。不得只改学科名称而复用空泛任务。
