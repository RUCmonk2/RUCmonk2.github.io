# 中小学全科学习导航与知识图谱

## 已实现范围

`/learning/k12/` 提供16个学科入口。数学保留199节详细双模式讲义和3张学段图谱；其他15个学科将当前目录中的671个主干主题展开为37张学段图谱，含798条学段内关系。合计40张图、870个知识点。

每个新节点独立编写直觉说明、精确定义或判断依据、具体例子、误区、自测题和带理由的解答，提供「从零理解 / 严谨表述」。两种模式共用概念事实，前者按理解步骤展开，后者优先呈现定义、边界与检验。答案默认折叠，知识联系在两种模式中均保持可见。原122个综合模块任务和6个跨学科项目继续保留。

这是当前课程目录主干主题的完整展开，不声称穷尽每套教材、竞赛内容或所有细分技能。外语图谱为英语主线，其他外语只有衔接提示；地方、校本课程没有独立图谱。科学保留小学和部分地区初中综合科学路径；物理、化学、生物、历史、地理从初中开始；通用技术只有高中。具体年级安排和选学范围结合在用教材。

范围参照教育部2022年义务教育课程方案与标准、2017年版2020年修订的高中课程方案与标准。解释、案例、任务与关系均由本站独立组织，不复制课文或试卷。法律节点附现行官方文本入口；体育节点附专项课标，实践活动明确适龄条件。

## 图谱与交互

复用 `MathMapGraph` 的宣纸背景、三色领域编码、分级墨点、楷体标签、力导向布局、悬停延迟聚焦、图内缩放、拖动、搜索、领域和路线筛选。点击只选中；「阅读完整讲解」主动进入下方详情。

非公式节点在预览区展示「想一想」问题；公式正文经 KaTeX 编译。新增可选 `AtlasNode.preview` 和 `KnowledgeAtlas.readingGuide/lessonKicker`，原数学和课程图保留原行为。标签字库扩充为845字符，仍为本地OFL字体子集。

关系由作者显式定义：`prereq` 为建议先学，`related` 为比较或应用联系。时间相邻不自动连成先修；不得按列表顺序批量造边。跨学段及跨学科链接放在节点的知识联系中，画布只显示当前学段，避免全科混在一起。先修图保持无环。

## 路由与入口

- 全科：`/learning/k12/`，学段卡片直达图谱，关键词可直达具体节点。
- 数学：`/learning/k12/mathematics/`，旧三学段、讲义和因式工坊地址保持。
- 学科目录：`/learning/k12/subjects/{subject}/`。
- 学段图谱：`/learning/k12/subjects/{subject}/knowledge-map/{stage}/`。
- 概念深链接：`#{stage}-{module}-{序号}`，编号从1开始。
- 原学段和模块锚点保留，图谱讲解可回到综合任务。
- 37张图均生成中文和英文路径；英文界面明确教学内容为中文。
- sitemap 收录全部图谱。讲解按需加载，避免把全部正文装进首屏。

## 内容与生成

- `src/data/k12-subjects/subjects.json`：范围清单，学科 → 学段 → 模块 → 主题。
- `content/k12-atlas/{subject}.json`：671个独立作者条目，模块内边、跨模块/学段边及跨学科桥。
- `scripts/build-school-lessons.mjs`：核对范围、字段、关系、先修无环、跨科目标和严格公式；生成讲解与图元数据。
- `public/assets/school-lessons/{subject}/zh/{node}.json`：生成资产，Git忽略，由构建产生。
- `src/data/k12-subjects/atlas-manifest.json`：生成的轻量元数据，纳入Git。
- `src/data/k12-subjects/atlas.ts`：适配共享图引擎、域中心、路线、来源与阅读提示。
- `index.ts`：路径、统计、框架和数学目录适配，目录组件无需加载整份图元数据。

作者节点字段为 `id/title/intuition/formal/example/question/answer/pitfall`。新增或修改主题应同步范围清单，保留已有ID以免深链接失效。每个主题需有独立例子与练习，不得用重复的模块任务填充。中文数学下标用 `\text{中文}`，公式置于数学分隔符内。非数学概念使用恰当的文本、证据或实践情境，不强套符号表。

`--partial` 仅用于作者编辑时预览；正式构建和CI必须无此参数，任何缺科或缺主题都会失败。不得发布部分manifest冒充全量。

## 验证与维护

全科字库检查需要 Python 3 与 `fonttools==4.62.1`；Pages CI 显式安装此依赖。

`npm run test:k12` 包括既有数学和因式分解门槛，并运行全科生成与 `check-school-atlases.mjs`。验证37/671覆盖、逐主题入口、无孤立图节点、跨模块联系、按需讲解唯一性、两种模式的答案边界、4974个正文内部链接、确定性布局、可见标签不重叠及字库覆盖。生成阶段执行816次严格公式渲染检查（含两种模式重复，不是独立公式数）。

`npm run build` 自动生成全科讲解。`check-site-export.mjs` 核对74个本地化图谱页面、671份导出资产与源生成资产一致，并识别图谱选择hash。发布继续执行 lint、内容、原数学/课程图谱、K12、构建和导出检查。

浏览器验收覆盖全科搜索直达节点、物理跨学段深链接、语文节点实际点击保持滚动位置、图内放大、语文与劳动两种阅读模式、折叠解答、390像素手机阅读与搜索列表、英文路径及中文内容提示。检查中无控制台错误和页面横向溢出。触控板手势和悬停状态机继续由共享引擎的既有测试覆盖。

增加中文标签后运行：

```sh
node scripts/subset-math-map-font.mjs /path/to/LXGWWenKai-Regular.ttf
```

保留原字体许可及 Atlas Kai 改名规则。图谱内容不收集学生个人数据，不需要账号或第三方统计。
