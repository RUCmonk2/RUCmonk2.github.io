# 中小学数学知识网与因式工坊

## 发布范围

- 199 节独立讲义：小学 48、初中 64、高中 87。
- 每节提供「从零理解」「严谨表述」，包含符号解释、具体例题、条件与误区；入门版各有 3 道练习及折叠的逐步解答，共 597 题。
- 3 张学段知识网复用现有墨点、宣纸、三色领域编码、悬停聚焦、图内缩放和阅读组件。
- 8 条学习路线、跨学段先修链接、按学段/主题检索、当前讲义打印、设备本地阅读标记。
- 22 种 SVG 图解用于 39 节讲义；图片可离线随站点资源加载，包含中文替代文本。
- 因式工坊：面积分合、边长滑块、基础 5 类与进阶 8 类随机题、3 档难度、分层提示、等价式判题、可复现题号链接。

内容按中国大陆课程主干组织。高中区分基础主干、选择性必修、拓展衔接；不把目录顺序宣称为全国统一年级进度，不声称覆盖所有竞赛题型。英文路由复用中文讲义并明确提示语言。

## 文件与数据流

| 位置                              | 作用                                                  |
| --------------------------------- | ----------------------------------------------------- |
| `src/data/k12/topics.json`        | ID、学段、领域、标题、先修、目标、代表公式与层级      |
| `src/data/k12/index.ts`           | 学段、来源、路线与共享图谱适配器                      |
| `content/k12/{stage}/{id}.md`     | 每节独立撰写的双模式正文                              |
| `scripts/build-k12-lessons.mjs`   | 校验内容、渲染所有公式、补充先修及参考链接、导出 JSON |
| `public/assets/k12-lessons/`      | 构建产物，不入 Git；图谱按需加载                      |
| `src/app/[locale]/learning/k12/`  | 总览、学段图谱、独立讲义路由                          |
| `src/components/k12/`             | 目录、讲义阅读、工坊、共享页面外壳                    |
| `src/lib/math-lab/`               | 有理数与二次根式多项式解析、出题、判题与公式文本分段  |
| `public/images/k12/`              | 代码生成的教学 SVG                                    |
| `scripts/generate-k12-figures.py` | 仅用 Python 标准库再生成图解                          |

正文开头一段用于图谱简介。`<!-- formal -->` 分隔阅读版本；`<!-- solutions -->` 把入门版的练习与解答分开。源码中只保留讲义自身内容；先修、后续、来源由构建器统一补充，避免手工维护重复链接。

公式必须放入 `$...$` 或 `$$...$$`。Markdown 表格中的绝对值请用 `\lvert...\rvert` 或 `\vert`，不要使用会被表格解析器识别为分隔符的裸竖线。每次增删图谱标签后更新 `scripts/subset-math-map-font.mjs` 生成的字体子集；沿用已有 LXGW WenKai 1.522、OFL 许可及 Atlas Kai 字体名称。

## 工坊判题的边界

用户输入经过受限语法解析，不传入 `eval` 或 `Function`。使用 BigInt 有理数逐项比较多项式，不依赖随机数值试代判断恒等性。支持省略乘号、括号、正负号、有限小数、常数除法及小整数幂。拒绝含变量的分母，限制输入长度、嵌套深度、次数和中间整数大小；先计算幂底，避免嵌套幂重复递归。

基础五类题与六类常规进阶题在有理系数范围内分解；另外两类根式题明确标注实数系数范围。允许交换因式顺序、整体负号抵消和有理数倍的等价表达；不把仅仅展开后相等当作完成分解。整数公因数的最大提取是参考答案的教学规范，但与「在有理系数范围不可再分」不同，不强行拒绝等价的非首一一次因式。基础题沿用单变量判题。进阶题使用稀疏多元多项式，按每个字母的指数向量与 BigInt 有理系数进行精确比较；先确认展开恒等，再将作答中的乘积、幂与常数倍归一，与生成器提供的有理数域不可约因式多重集比较。该策略允许立方公式中不可约的二次因式、重复因式及有理数倍换序，拒绝尚未拆开的可约括号；不作为任意外部多项式的通用分解服务。

进阶题包括立方和差、四次／六次换元、分组分解、多字母提公因式、二元二次式、多字母综合、根式平方差及根式系数分解；按种子选择 x/y/z 或 a/b/c，最多三个独立变量。进阶输入支持可增减的因式括号及完整式子两种形式，系数不固定为 1。解析器接受六种字母，指数 0—8、总次数最多 12，最多 128 个展开项、60,000 次项乘法；这些是书写与资源限制，出题次数为二至六次。

根式题每题选定一个根号基底 d∈{2,3,5,7}，使用 BigInt 有理数对 `(a,b)` 表示 a+b√d，精确进行四则运算、常数除法有理化、符号判断和系数比较；因式在对应数域 Q(√d) 中按非零常数倍归一。这些生成题的最终因式在实数系数范围内也不可再分。支持 `√2`、`sqrt(2)`、同类根式化简（如 √8=2√2）与整数平方根；根号内只接受 0—10000 的整数，其他根号基底提示先化简。当前不支持复数、字母根式或混合多个独立根号基底；小数近似值不会冒充精确的无理数答案。独立数值试代只用于生成器测试，线上判题始终逐项精确比较。

题号通过 URL hash 保存种子、题型与难度，刷新可恢复。旧五类题的种子与题目保持兼容，模式由题型恢复。所有计算在浏览器本地进行，不创建学生账户或上传作答记录。阅读标记仅表示读过，不能当作掌握度；本次完成题数刷新后重置。

## 验证与发布

使用 Node 22：

```sh
npm run test:k12
npm run lint
npm run test:content
npm run test:math-map
npm run build
npm run check:export
```

`test:k12` 包括：

- 全部 199 节必须存在；阅读版本、符号表、3 题及解答不能缺项。
- KaTeX 严格模式校验正文与图谱公式，不允许未包裹的常见 LaTeX 命令、残留占位。
- 知识点 ID、先修有向无环图、路线、学段边与布局中心检查；布局可重复、坐标有限、已显示标签不重叠。
- 直接解析正文检查支持语法范围内的 575 个数值等式。明确标注的错误示范有逐项例外，符号证明不冒充自动验证。
- 图解存在性、替代文本、Markdown 表格结构、先修链接完整性。
- 2,250 道基础题与 2,400 道进阶题，参考答案精确判题、五点独立试代、换序/有理及根式系数/根式有理化/小数近似拒绝/错误/未完成/非法输入、嵌套幂边界，以及所有提示和步骤的严格公式排版。

完整构建导出所有讲义路由，导出检查再次核对实际部署资产与本地内容、页面和链接。GitHub Pages 工作流包含这些发布门槛。`--partial` 仅供作者中途检查，不进入发布构建。

浏览器验收应覆盖总览检索、三学段图谱、独立讲义双模式和解答、手机宽度、工坊滑块/提示/判题/恢复链接。打印当前模式；先展开解答才打印答案。增加功能时继续复用现有阅读与图谱风格。
